# Indoor Plants 🌿

An elegant and responsive web application designed for indoor plant enthusiasts. Explore a wide range of indoor plants, learn about plant care, and enhance your living space with greenery.

🌐 **Live Demo:** [https://hassanroki.github.io/indoreplants/](https://hassanroki.github.io/indoreplants/)

---

## 🛠️ Technologies Used (টেকনোলজি)

- **HTML5**: Semantic markup for structured content.
- **Tailwind CSS (`v4.1.12`)**: Utility-first CSS framework for modern and responsive styling.
- **JavaScript (ES6+)**: Interactive client-side dynamic behaviors (e.g., dynamic copyright year).
- **Node.js & npm**: Development environment and package management.

---

## 📋 Prerequisites & Version Requirements (প্রয়োজনীয়তা ও ভার্সন)

Before running the project locally, ensure you have the following installed on your system:

- **Node.js**: `>= 18.x` or later (LTS version recommended)
- **npm**: `>= 9.x` or later (comes bundled with Node.js)
- **Git**: For repository management

---

## 🚀 Getting Started (ইনস্টলেশন ও রান করার নিয়ম)

Follow these step-by-step instructions to get a local copy up and running:

### 1. Clone the Repository (গিট থেকে ক্লোন করুন)

```bash
git clone https://github.com/hassanroki/indoreplants.git
```

### 2. Navigate to the Project Directory (প্রজেক্ট ফোল্ডারে প্রবেশ করুন)

```bash
cd indoreplants
```

### 3. Install Dependencies (ডিপেন্ডেন্সি ইনস্টল করুন)

```bash
npm install
```

### 4. Build & Watch Tailwind CSS (টেইলউইন্ড সিএসএস ওয়াচ চালু করুন)

Run the build script to watch for changes in `input.css` and automatically compile them to `output.css`:

```bash
npm run build
```

---

## 💻 Viewing the Project (প্রজেক্ট দেখার উপায়)

Since Tailwind CSS CLI runs in watch mode, open `index.html` in your web browser:

1. **VS Code Live Server**: Right-click `index.html` and select **"Open with Live Server"**.
2. **Direct Browser Open**: Open `index.html` directly in your favorite modern browser (Chrome, Edge, Firefox).
